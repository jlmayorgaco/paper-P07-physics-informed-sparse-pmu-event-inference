# Figure roadmap

No numerical figure should be created until its source data and campaign manifest exist. Each figure must be regenerated by a version-controlled script and include a caption that names the study, PMU membership, simulator, split, and uncertainty treatment.

## Production rules

- Use vector output for diagrams and line plots when possible; use readable IEEE-compatible fonts and no screenshot-only graphics.
- Store source data or a reproducible data-extraction path, plotting script, configuration, and generated output together.
- Do not encode a numerical claim in a visual title or caption before the underlying campaign is frozen.
- If a figure uses uncertainty bands, state whether they are repetitions, bootstrap intervals, posterior intervals, or another quantity.
