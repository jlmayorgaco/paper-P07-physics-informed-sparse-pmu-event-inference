# Detection, family and site inference across two consecutive decision windows

Two prospectively frozen simulations, each with 128 independent trajectories and 256 window decisions. Truth uses the continuous state of the nonlinear ten-machine IEEE-39 plant. Currents are the eight archived, oriented B01 terminal channels with instrument noise; voltage noise follows the preceding branch study. Each simulation has 192 events and 64 quiet windows. Each of the sixteen ordered mode pairs occurs eight times. Inference sees only the 32 measured channels, never the true family, source, parameter realization or presence of an event. Outputs are available at each three-second boundary. Known window structure, onset grid, one-second event duration, calibrated instruments and known network restrict the scope. There are no field data or nine-class M9 decisions here.

The original protocol and implementation are cfc3b97 and c3d5354. The second protocol and implementation are 737ea5c and 5afd4a4. Single-operator prediction hashes were written before scoring. Weak shunt pulses, generator torque increments and base-load increments compete with quiet. Uniform amplitude is integrated analytically with a truncated Gaussian integral and the onset is summed. The particle variant samples sixteen first-window histories and continues their recovery. Windowwise whitening neglects incremental noise information at the window boundary. The successor also estimates uncertainty in the recovery via twelve variably forced trajectories, conditioning their joint Gaussian approximation on the first-window residuals before scoring the second window. Particle proposals use the first-window nominal posterior. The second intervention uses additive dynamic templates. No learned attention module was used.

The initial history filter reached 165/192 joint hits with 17 false alarms on seed 476209. A new seed was used to evaluate the correction. On seed 643271 the successor gained five exact events and lost none relative to the initial particle rule on the same inputs. A whole-record bootstrap puts the paired difference at +0.53 to +4.95 percentage points (95% percentile interval). The successor gave correct family and site for 48/64 weak, 59/64 generator and 64/64 load events. Twelve recovery-only windows triggered false alarms, seven after load changes and five after generation changes. It handled both windows without any error on 97/128 records. Overall joint accuracy is 89.06%. This differs from site accuracy with family supplied.

## Reproduction

Set P07_SCIENCE_ARCHIVE and OPENBLAS_NUM_THREADS=1 as in the preceding branch_current_trial, which records hashes of the source network and noise inputs. From this directory invoke Python on run_stream.py with generate, predict and score in order, then recovery_ensemble.py with the same three stages. Run paired_summary.py to recompute paired results and observation hashes. The score scripts check the prediction hashes. Order of the confusion matrices is quiet, weak, generation, load. As independent numerical checks, the nonlinear trajectory matched the predecessor for three isolated interventions, the amplitude likelihood matched numerical quadrature on four cases, and the conditional Gaussian quadratic forms and log determinant matched a dense covariance calculation.
