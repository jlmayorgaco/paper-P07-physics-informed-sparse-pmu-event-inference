# Prospective nine-state supervised stream trial
Simulate complete 24-second IEEE-39 records, 10 classical machines, governors and algebraic bus voltages. Observe only eight voltage/current PMUs at 30 Hz. Solve state continuously across interventions and restorations. One channel represents each oriented branch phasor as in the B01 audit. Use three-phase-balanced positive sequence. Physical families are a bus fault, temporary non-islanding branch outage, generator torque change, load change and weak shunt. Telemetry families are missing reports or biased samples, with composite generation+missing and weak shunt+measurement corruption. These are a new physical realization of nine study labels, not official competition records. Family 0 means no new event; do not emit an alarm for 0. Use true bus, line, or affected PMU for the primary origin. For compound events this is the physical origin.
 
Generate 700 complete independent training trajectories and 300 new test trajectories, seeds 710993 and 845219. Train both family and site predictors on measurement-derived causal features. Fix forests and alarm rules before test. Reserve every report from a trajectory on the same side. Draw 0/1/2/3 target events with probabilities .20/.25/.35/.20; for multiple events include both independent draws and repeated family and site. Randomize report-level onsets, sites, intensity, duration, inertia, damping and measurement noise. Guarantee a clean initial one-second calibration prefix and gaps between target onsets. Catalog is known on both sides. No family, site, time or event count is provided to inference. Score event precision/recall, false alarms on entire normal records and on all unmatched times, nine-class macro-F1, correct family, exact origin and joint success over all true events. Match each alarm once only at or after onset and within 1.5 seconds. Count duplicates and late alarms as extras and unmatched events as missed. Report median/95th delay among matched alarms, confusion and source breakdown. Report exact whole records and confidence via record bootstrap. Freeze model before generating the test data; no tuning on the test set.
