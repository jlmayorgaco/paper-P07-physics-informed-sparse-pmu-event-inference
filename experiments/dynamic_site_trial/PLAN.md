# Frozen decision protocol
Use the independent classical-machine IEEE-39 plant in history_conditioning, with governor dynamics and eight voltage PMUs at 30 Hz. This tests a physical proxy for the weak pulse in M9, a load increment, and a mechanical generation increment. Supply the family throughout. Each is a 1 s rectangular forcing. The weak pulse is a small active shunt on any bus; the load increment changes both P and Q on a base load and generation perturbs the corresponding machine input.
 
Compare a sustained frozen-rotor response (same reports and onset/amplitude search), dynamic response with known strength/onset, and dynamic with unknown strength/onset. Also score static given strength/onset, and remove each voltage channel group. Use nominal 1% injections on a 100 MVA base (weak), 10% base load, 0.1 pu generation. Use independent Gaussian measurement noise SD 0.001 log magnitude and 0.001 radian. These are specified experimental levels, not calibrated competition noise. Use no true-state signals at inference. For calibration construct nominal templates only from physical model parameters. Group sites by sorted bus, modulo three; reserve index 0 modulo three in each family for blind evaluation; all sites compete. Predeclare six draws per site, unseen strengths uniform 0.7–1.3, grid onset 3–12 frames, 90 reports. Simulate nominal calibration and vary truth inertia and damping by independent factors uniform 0.8–1.2. Compare by family, paired flips and site-cluster uncertainty. Generator operating point and network topology fixed. Development seed 84721 and blind seed 59803. Seal predictions before scoring each split. Run independent synthetic nine-class transfer only if development full dynamic exceeds static and reaches 95% in each physical family. Keep the existing nine-class result otherwise. No tuning or second attempt on these cohorts.
