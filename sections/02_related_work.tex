\section{Related Work and Exact Research Gap}
\label{sec:related-work}

\subsection{State Estimation With Incomplete Models or Measurements}

Power-system dynamic state estimation combines machine, control, load, and network models with high-rate synchronized measurements. The task-force review in \cite{zhao2019dse} separates dynamic, tracking, forecasting-aided, and static formulations and identifies model uncertainty and measurement availability as persistent constraints. Robust Gaussian filters address outliers or non-Gaussian measurement noise \cite{zhao2018gmukf,li2023eventtriggered}; these are different failure modes from a stale network or equilibrium center. Katanic \emph{et al.} estimate differential and algebraic states directly in a partially known nonlinear DAE and derive a topological estimability condition \cite{katanic2024recursive}. Nguyen \emph{et al.} instead estimate states and unknown inputs in distributed active networks \cite{nguyen2021unknown}. Both establish that state and nuisance input can be inferred jointly, but neither uses the event-family/source contract or integrity composition studied here.

Learning methods recover states under sparse or heterogeneous measurements by encoding graph structure, power-flow relations, or a model-based estimator in the representation. Ngo \emph{et al.} combine a graph neural network with physics-based state estimates \cite{ngo2024pignn}; Yue \emph{et al.} couple graph learning to a robust distribution-system state estimator and include sparse-PMU line-outage identification \cite{yue2024graph}. These methods broaden the estimator family, but their distribution-system measurements and targets do not provide a common benchmark for the transmission-event source problem.

\subsection{Sparse-PMU Event and Source Inference}

PMU event identification has been addressed through subspace methods, engineered features, transfer learning, and graph models \cite{li2018subspace,yuan2021learning,li2022transfer,yuan2023gnn}. Cheng \emph{et al.} demonstrate label-light online detection on a large field-PMU stream \cite{cheng2022bigan}, while Abdel Hai \emph{et al.} study transfer when only a small labeled set is available \cite{abdelhai2021transfer}. These works establish strong detection contracts, but event presence is not physical-source recovery. Pandey \emph{et al.} jointly detect, classify, and localize events using synchrophasor measurements and system information \cite{pandey2020realtime}. Sparse-PMU methods locate faulted lines, generation losses, or outages using learned models and electrical structure \cite{li2019cnn,azizi2021log,azizi2023line,yildiz2024few}. Group-sparse dictionaries use admittance-, impedance-, and injection-based response models to localize several disturbance types with limited measurements \cite{wang2024group}; a spatiotemporal graph model can also embed event-type, topology, and localization-cost knowledge in its loss \cite{li2024knowledge}.

Benchmark availability does not remove the contract problem. The pmuBAGE collection offers almost one thousand privacy-preserving generated event records learned from field data \cite{foggo2024pmubage}; it is useful for standardized event analytics but does not by itself certify physical source holdout. Measurement integrity is also a distinct inference variable. Chatterjee \emph{et al.} separate event-induced excursions from spurious outliers before robust PMU recovery \cite{chatterjee2020robust}, and Biswas \emph{et al.} curate utility examples of missing, locked, quantized, and timing-affected synchrophasors \cite{biswas2025quality}. Their evidence supports explicit integrity modeling instead of folding sensor failures into physical event classes.

These works show that limited PMU coverage is not by itself a new problem. The unresolved issue is the evaluation contract. Many classifiers learn a fixed list of asset labels, so testing another replica at a known source measures interpolation rather than source generalization. Zhai \emph{et al.} reconstruct full state and localize line attacks from partial observations using an LSTM across multiple benchmark networks \cite{zhai2025partial}. Rimkus \emph{et al.} reconstruct missing trajectories without fault-location labels before applying a localization method \cite{rimkus2025gnn}. These are direct conceptual competitors and prevent us from claiming to be the first to connect state reconstruction and localization. They do not, however, jointly represent the eight physical/integrity event states used here or test the exact held-source, diagnosability, and model-mismatch contract.

\subsection{Observability, Diagnosability, and Sensor Value}

Functional observability asks whether a requested function of state can be inferred without full-state observability \cite{fernando2010functional,zhang2025functional}. PMU placement based on empirical observability Gramians similarly treats sensor value as task dependent \cite{qi2015placement,sun2016observability}. For event sources, Jamei \emph{et al.} derive placement-dependent performance limits for fault localization \cite{jamei2020limits}; Conte \emph{et al.} prove sparse-PMU fault-localization conditions that partition a radial grid into indistinguishable line clusters \cite{conte2023fault}; and Yildiz and Abur optimize sparse placement for event detection and identification \cite{yildiz2025sparse}. These studies motivate the present separation between hidden-state reconstruction and pairwise hypothesis information. They also impose a restraint: one fixed eight-PMU set cannot support a general optimal-placement claim.

\subsection{Research Gap and Claim Boundary}

Table~\ref{tab:literature-capability} exposes the remaining intersection rather than an absence of methods. The target is a source-agnostic physical hypothesis evaluated from sparse PMUs while (i) an unobserved state trajectory is estimated, (ii) physical interventions and measurement failures can coexist, (iii) source ambiguity is related to sensing geometry before a classifier is trusted, and (iv) generalization is tested on physical assets excluded from source-labeled training. A learned component is useful only if it improves model discrepancy or proposal efficiency without reverting to asset-label memorization.

The current evidence does not complete that intersection. It validates hidden-voltage estimation and physical recentering in PowerDynamics, and it audits a known-source event classifier plus source-transfer failure in ANDES. The proposed joint inference and diagnosability-to-posterior experiment remain the paper's next falsifiable step. This wording is intentionally narrower than the title's long-term objective and should be revised again if the end-to-end campaign is not completed before submission.
