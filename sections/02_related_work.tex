\section{Prior Work and Research Gap}
\label{sec:related-work}

\subsection{State, Algebraic Variable, and Unknown-Input Estimation}

Power-system dynamic state estimation combines machine, control, load, and network models with high-rate synchronized measurements. The task-force review in \cite{zhao2019dse} separates dynamic, tracking, forecasting-aided, and static formulations and identifies model uncertainty and measurement availability as persistent constraints. Gaussian-sum and event-triggered filters address outliers or non-Gaussian measurement noise \cite{zhao2018gmukf,li2023eventtriggered}; a stale network or equilibrium center is a different model error. Nugroho \emph{et al.} construct observers for differential and algebraic DAE states with unknown inputs and input-sensor failures \cite{nugroho2022dae}. Katanic \emph{et al.} estimate the same state types in a partially known nonlinear DAE and derive a topological estimability condition \cite{katanic2024recursive}. Qu \emph{et al.} derive an event-triggered joint state/unknown-input estimator for multi-machine grids \cite{qu2023joint}, while Nguyen \emph{et al.} use distributed state-input estimation in active networks \cite{nguyen2021unknown}. Joint state/input estimation is therefore established. Those unknown inputs, however, do not define a multi-family physical-source bank with a simultaneous integrity state.

Learning methods recover states under sparse or heterogeneous measurements by encoding graph structure, power-flow relations, or a model-based estimator in the representation. Ngo \emph{et al.} combine a graph neural network with physics-based state estimates \cite{ngo2024pignn}; Yue \emph{et al.} couple graph learning to an outlier-resistant distribution-system estimator and include sparse-PMU line-outage identification \cite{yue2024graph}. Moshtagh \emph{et al.} address PMU-unobservable transmission state estimation with a topology-aware graph architecture tested under topology change, PMU failure, bad data, and non-Gaussian noise \cite{moshtagh2025topology}. These methods reconstruct state under incomplete or faulty sensing. Tolerating an outage does not, by itself, identify the outaged line.

\subsection{Sparse-PMU Event and Source Inference}

PMU event identification has been addressed through subspace methods, engineered features, transfer learning, and graph models \cite{li2018subspace,yuan2021learning,li2022transfer,yuan2023gnn}. Cheng \emph{et al.} demonstrate label-light online detection on a large field-PMU stream \cite{cheng2022bigan}, while Abdel Hai \emph{et al.} study transfer when only a small labeled set is available \cite{abdelhai2021transfer}. Their targets are event presence or family. Physical-source recovery is a separate output. Pandey \emph{et al.} jointly detect, classify, and localize events using synchrophasor measurements and system information \cite{pandey2020realtime}. Sparse-PMU methods locate faulted lines, generation losses, or outages using learned models and electrical structure \cite{li2019cnn,azizi2021log,azizi2023line,yildiz2024few}. Group-sparse dictionaries use admittance-, impedance-, and injection-based response models to localize several disturbance types with limited measurements \cite{wang2024group}; a spatiotemporal graph model can also place event type, topology, and localization cost in its loss \cite{li2024knowledge}.

Open-set recognition differs from source holdout. Kummerow \emph{et al.} use Siamese recurrent embeddings to reject event types or locations absent from training \cite{kummerow2022siamese}; their subsequent sigmoid-network formulation learns class-dependent rejection boundaries under limited and full PMU coverage \cite{kummerow2023sigmoid}. Hu and Cheng use generative sliding-window evidence and decision fusion to assign unseen events to a dedicated open category \cite{hu2026openset}. Open-set methods decide whether an observation falls outside a learned class set. Source generalization asks whether an untrained but physically enumerable bus or line can be evaluated as a counterfactual source. Rejection and physical candidate ranking answer different questions.

Benchmark availability does not remove the evaluation problem. The pmuBAGE collection offers almost one thousand privacy-preserving generated event records learned from field data \cite{foggo2024pmubage}; it is useful for standardized event analytics but does not by itself certify physical source holdout. Measurement integrity is also a distinct inference variable. Chatterjee \emph{et al.} separate event-induced excursions from spurious outliers before corruption-tolerant PMU recovery \cite{chatterjee2020robust}, and Biswas \emph{et al.} curate utility examples of missing, locked, quantized, and timing-affected synchrophasors \cite{biswas2025quality}. Their evidence supports explicit integrity modeling instead of folding sensor failures into physical event classes.

Limited PMU coverage is already a well-studied problem. The unresolved issue is the evaluation protocol. Many classifiers learn a fixed list of asset labels, so testing another replica at a known source measures interpolation rather than source generalization. Kummerow and Bretschneider show that measurement noise, unseen operating points, and unseen disturbances materially change the evaluation of learned PMU classifiers \cite{kummerow2023nuisance}. Zhai \emph{et al.} reconstruct full state and localize line attacks from partial observations using an LSTM across multiple benchmark networks \cite{zhai2025partial}. Rimkus \emph{et al.} reconstruct missing trajectories without fault-location labels before applying a localization method \cite{rimkus2025gnn}. Together these works establish reconstruction followed by localization as prior art. They do not jointly represent the eight physical/integrity states used here or test the held-source, diagnosability, and model-mismatch conditions together.

\subsection{Observability, Diagnosability, and Sensor Value}

Functional observability asks whether a requested function of state can be inferred without full-state observability \cite{fernando2010functional,zhang2025functional}. Unknown-input observability instead asks whether exogenous inputs can be reconstructed from output histories \cite{hou1998input}; sparse strong observability extends the question to corrupted sensor sets \cite{showkatbakhsh2020secure,sun2026secure}. PMU placement based on empirical observability Gramians similarly treats sensor value as task dependent \cite{qi2015placement,sun2016observability}. For event sources, Jamei \emph{et al.} derive placement-dependent performance limits for fault localization \cite{jamei2020limits}; Conte \emph{et al.} prove sparse-PMU fault-localization conditions that partition a radial grid into indistinguishable line clusters \cite{conte2023fault}; and Yildiz and Abur optimize sparse placement for event detection and identification \cite{yildiz2025sparse}. These results distinguish hidden-state reconstruction, input reconstruction, and pairwise source separation. They also rule out a general optimal-placement claim from one prescribed eight-PMU set.

\subsection{Remaining Technical Gap}

Table~\ref{tab:literature-capability} separates the capabilities needed for the combined problem. A source-agnostic physical hypothesis must be evaluated while the unobserved trajectory is estimated and measurement failures remain possible. The sensing geometry must expose indistinguishable sources before a classifier is trusted. Evaluation must then exclude the physical source asset from all source-labeled fitting. Under this protocol, learning is useful only when it corrects model discrepancy or reduces candidate-search cost without memorizing asset labels.

The available evidence covers only part of this intersection. PowerDynamics supports hidden-voltage estimation and physical recentering. ANDES supports known-source event recognition and documents failure under source holdout. Joint candidate-conditioned inference and the predicted relation between separation and uncertainty still require a common experimental contract.
