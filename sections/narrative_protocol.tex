\section{Experimental Design}
\label{sec:narrative-protocol}

\subsection{Plant, Measurements and Scoring}
The original IEEE 39-bus simulator (F01), built in Julia with
PowerDynamics \cite{plietzsch2022powerdynamics}, uses Sauer--Pai machines,
IEEE Type~I exciters, TGOV1 governors and the constant-impedance
component of ZIP loads. Each 120-s event record follows one uninterrupted
trajectory through six load or line interventions. Each normal record
lasts 600\,s. At 30 reports/s these records contain 3,601 and 18,001
reports per PMU, including both endpoints. A switch-aligned report uses
the post-switch algebraic solution. The candidate at bus~31 is the
9.2-MW/4.6-Mvar load colocated with the generator that serves as slack
in the initial power flow. Machine dynamics balance the subsequent load change.

The simulator adds instrument noise fitted to normal segments of the
competition reference record. Vector autoregressions for each signal
family include a strong component shared across PMUs. Voltage-magnitude
noise is about 0.4\% of nominal, while noise in inter-PMU angle
differences ranges from $10^{-4}$ to $10^{-2}$ degrees. Independent
errors at the instrument terminals can obscure the small differences on
which remote load attribution relies (Section~\ref{sec:noise-stress}).

The first 12\,s of each record are reserved for startup. For each true
intervention, the evaluator associates the first unassigned alarm after
onset, up to the next onset or a 30-s cap, using timestamps alone. A
\emph{timely attribution} requires the diagnosis attached to that alarm
to name both the correct family and the correct asset before true
restoration. An unmatched alarm on an event record counts as an extra.
Alarms on normal records have their own exposure. Intervals for method
differences use 10,000 paired bootstrap resamples of complete trajectories.
Predictions were fixed before scoring against the reserved event labels.

\subsection{Comparison With a Continuous GLR and ExtraTrees}
\label{sec:comparison-design}
Each procedure receives the same 47 PMU coordinates and covers the same
18 sources. The history bank and continuous GLR (generalized likelihood
ratio) observer share the nominal network, measurement operators and
startup data. The GLR commits to one state, carries it through
restoration and fits load severity over a bounded interval while searching
19 possible onset reports. ExtraTrees, an ensemble of randomized trees
\cite{geurts2006extremely}, scores sources from causal PMU features. Its
separate training set covers all catalog sources.

For each procedure, threshold selection used 12 event and 24 normal
calibration trajectories. Eligible thresholds completed every record
and gave a one-sided 95\% Poisson upper bound of at most one alarm per
monitored normal hour. Among eligible settings, we maximized timely
attribution, breaking ties by fewer extras, shorter diagnosis delay and
then higher threshold. Each GLR threshold required a separate run because
a published decision changes the state used for the next prediction.
The selected score thresholds were 6.9068 for the bank and GLR and 2.1972
for ExtraTrees. Each threshold applies on its procedure's own score scale.
The test comprised \RecParents{} event and \RecNormalParents{} normal
trajectories. Interventions lasted 2--5\,s, with 3--8\,s between one
restoration and the next onset. The paired bootstrap preserved the network
and noise strata.

\subsection{Controlled Comparison of Recovery Representations}
All three arms use the nominal F01 predictor, the same severity model,
proposal rules and publication clock. The \emph{history} arm keeps the
retained paths and proposal memory when it publishes a restoration.
The \emph{mean} arm (carry in Fig.~\ref{fig:c03}) merges the no-event
path and the restored paths into their weighted augmented-state mean,
keeps active paths, and uses the shared conditional covariance. It clears
stored pre-onset states and restarts the proposal windows from the
merged state. The \emph{reset} arm performs the same merge and
additionally sets the 114 physical-state deviations to zero.
Instrumental coordinates remain in the merged state. History versus mean
therefore compares two ways to continue inference after a published
restoration. Mean versus reset tests whether the physical component
of the merged state should be carried forward.

On F01, 36 event and 36 normal calibration trajectories determined one
threshold per arm under the same normal-alarm budget. We applied those
thresholds to two test plants. F01 uses the original dynamics. P2
retains the same topology, terminals and catalog but uses classical
machines, droop governors and different passive parameters. The F01
predictor was applied to P2 without refitting the plant model. Each test
plant contributed 36 new event and 36 normal trajectories, with event
schedules, sources and noise seeds paired across plants.

Each test sequence contains four interventions after short recovery gaps
(at least 0.5 and less than 3\,s) and one after a
3--8-s gap, in randomized order. The first intervention has no preceding
gap. The prespecified endpoint thus includes 144 short-gap interventions
out of 216 per plant. A coverage advantage required a difference of at
least five percentage points, a paired 95\% interval above zero and
compliance by both compared arms with the normal-alarm budget on that plant.
