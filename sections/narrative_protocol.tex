\subsection{Primary Comparison}
\label{sec:comparison-design}
All three procedures see the same 30-report/s PMU stream and the same
18-source load and line catalog. The two physical procedures also share the
nominal network and measurement operators and the allowed startup prefix.

We select each threshold using 12 event and 24 normal calibration records.
A setting is feasible if it completes all records and its one-sided 95\%
Poisson upper bound is at most one normal alarm per monitored hour.
Selection favors higher timely attribution, then fewer extra alarms,
shorter diagnosis delay and a higher threshold, in that order.
The GLR is rerun for each candidate threshold because publication changes its
committed state. The held-out test has \RecParents{} event sequences with
six interventions each and \RecNormalParents{} normal records. The next
intervention begins 3--8\,s after OFF. We finalize the predictions before
scoring them against reserved labels.

For continuous events, an alarm is associated temporally before predicted family/source is inspected. The first unmatched alarm after ON is eligible up to the next ON, with the inherited 30-s cap. A timely joint decision requires the correct family and asset emitted before true OFF. Unmatched alarms are extras; false restorations and open episodes are reported separately. These definitions prevent an eventual correct answer from hiding a late diagnosis.

We report unmatched alarms during event records separately from alarms during
normal operation. The uncertainty analysis resamples whole physical parents
in pairs (10,000 draws). Report timestamps measure decision delay. Wall-clock processing time
measures computational cost.

\subsection{Plant and Secondary Tests}

The plant is an IEEE-39 model in Julia/PowerDynamics with Sauer--Pai machines, IEEE Type~I exciters, TGOV1 governors and constant-impedance ZIP loads. Each physical parent is integrated continuously, preserving differential states through ON/OFF. The PMU reporting grid is separate from solver steps: a 120-s record contains 3601 reports per PMU and a 600-s normal record contains 18001. At a switch-aligned report the export uses the post-switch algebraic value. The bus-31 candidate is the existing 9.2-MW/4.6-Mvar load at the generator bus that serves as slack only in the initial power flow; the dynamic model has no slack bus, so its load change is absorbed by machine dynamics like any other.

Instrument noise follows a stochastic model fitted to normal segments of the competition reference record: per-family vector autoregressions with a strong common factor across PMUs. Voltage-magnitude noise is about 0.4\% of nominal, but the noise of angle \emph{differences} between PMUs is only $10^{-4}$ to $10^{-2}$ degrees, because most angle noise is common to all units. This small differential noise is what makes megawatt-scale changes observable at remote PMUs (Section~\ref{sec:theory}); it is a property of the reference data, smaller than the idiosyncratic error expected from field PMUs \cite{iec2018synchrophasor}. Section~\ref{sec:noise-stress} therefore tests larger and independent per-PMU noise.

The component study tests state continuity with the same observations,
predictor and original thresholds in all arms. At inferred closure, one
pair keeps the augmented state and the other zeros only the 114 physical
state deviations. Within each pair, the load score either marginalizes or
profiles severity. This is a retrospective comparison on previously examined
records. It isolates the selected estimator changes at fixed thresholds.

An independent continuous evaluation varies network resistance and
reactance (R/X) and instrumental noise across 18 event and 12 normal
parents. It uses the original operating points of the five-model bank, the
nominal bank and two earlier ExtraTrees adapters. Its persistent-line lane
also includes the first-stop detector of Chen \emph{et al.}
\cite{chen2016quickest}. The supplement records that lane and the
comparator lineage. The independent per-PMU noise replay in
Section~\ref{sec:noise-stress} changes the measurement law directly.
