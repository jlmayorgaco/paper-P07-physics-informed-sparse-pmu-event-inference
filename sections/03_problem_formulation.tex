\section{Joint State, Event, and Source Problem}
\label{sec:problem-formulation}

\subsection{Hybrid DAE and Electrical Measurement Model}

Let $\bm x(t)\in\mathbb R^{n_x}$ denote differential states, $\bm z(t)\in\mathbb R^{n_z}$ algebraic states, $\bm u(t)$ scheduled inputs, $\bm q(t)$ network configuration, and $\bm\theta_k=\bm\theta_0+\bm G_\alpha\bm\alpha_k$ physical parameters with a slowly varying operating coordinate $\bm\alpha_k$. A physical intervention $\bm a_h(t)$ is indexed by hypothesis
\begin{equation}
 h=(c,\mathcal S,\tau,\bm a,\bm d), \qquad h\in\mathcal H,
 \label{eq:physical-hypothesis}
\end{equation}
where $c$ is event family, $\mathcal S$ is a bus or branch support, $\tau$ is onset, $\bm a$ contains signed severities on that support, and $\bm d$ describes the allowed temporal profile. A single-source event has $\mathcal S=\{\ell\}$ and scalar severity $\gamma=a_\ell$. The evaluated load contract fixes $c$ and $\tau$ and uses
\begin{equation}
 \mathcal S\subseteq\mathcal L,\qquad K=|\mathcal S|=\|\bm a\|_0\le2,
 \qquad |\mathcal L|=16, \label{eq:sparse-load-support}
\end{equation}
which gives one no-event, 16 single-source, and $\binom{16}{2}=120$ two-source hypotheses. The plant is
\begin{align}
 \dot{\bm x}(t)&=\bm f\!\left(\bm x,\bm z,\bm u,\bm q,\bm a_h;\bm\theta_k\right)+\bm w_x(t), \label{eq:dae-dynamic}\\
 \bm 0&=\bm g\!\left(\bm x,\bm z,\bm u,\bm q,\bm a_h;\bm\theta_k\right), \label{eq:dae-algebraic}\\
 \bm y_k&=\bm M_k\!\left[\bm h_{\mathcal P_k}(\bm x_k,\bm z_k,\bm q_k;\bm\theta_k)+\bm b_k\right]+\bm v_k. \label{eq:dae-measurement}
\end{align}
Here $\bm M_k$ selects the channels that are available at time $k$, $\bm b_k$ is a measurement-corruption process, and $\bm v_k$ is measurement noise. A dropout changes $\bm M_k$; bad data change $\bm b_k$; neither is a physical input to \eqref{eq:dae-dynamic}--\eqref{eq:dae-algebraic}. This separation permits a physical event and a measurement failure to coexist.

The latent variables have deliberately different time scales and meanings. The pair $(\bm x,\bm z)$ is the fast dynamic--algebraic state; $\bm\alpha$ is slow operating-point or parameter drift; $\bm a_h$ is an abrupt, sparse physical intervention; $\bm q$ is a discrete network mode; and $(\bm M,\bm b)$ describes data availability and corruption. A colored model-discrepancy state $\bm c_k$ may enter either the process or measurement residual, as tested in Section~\ref{sec:estimation}, but is not interchangeable with an event.

Within a smooth mode, assume the DAE is locally index one, so $\bm g_{\bm z}$ is nonsingular after the reference-angle constraint is imposed. Differentiating the algebraic constraint gives
\begin{equation}
 \dot{\bm z}=-\bm g_{\bm z}^{-1}
 \left(\bm g_{\bm x}\bm f+\bm g_{\bm u}\dot{\bm u}
 +\bm g_{\bm\theta}\dot{\bm\theta}\right). \label{eq:dae-index-one}
\end{equation}
Equation~\eqref{eq:dae-index-one} is not applied across a fault insertion or topology switch, where algebraic variables can jump and the model must be segmented. Differential states remain continuous unless a simulator-specific reset map is declared.

The algebraic network core is
\begin{equation}
 \bm I=\bm Y_{\mathrm{bus}}(\bm q,\bm\theta)\bm V,
 \qquad S_i=P_i+\mathrm jQ_i=V_i I_i^{*}. \label{eq:network-core}
\end{equation}
Writing $\bm Y_{\mathrm{bus}}=\bm G+\mathrm j\bm B$ and $V_i=|V_i|e^{\mathrm j\vartheta_i}$ gives
\begin{align}
 P_i&=|V_i|\sum_j|V_j|\!\left[G_{ij}\cos\vartheta_{ij}+B_{ij}\sin\vartheta_{ij}\right], \label{eq:ac-p}\\
 Q_i&=|V_i|\sum_j|V_j|\!\left[G_{ij}\sin\vartheta_{ij}-B_{ij}\cos\vartheta_{ij}\right], \label{eq:ac-q}
\end{align}
where $\vartheta_{ij}=\vartheta_i-\vartheta_j$. A line outage changes the branch primitives and therefore $\bm Y_{\mathrm{bus}}$; a bus fault adds a shunt-admittance intervention; generation and load changes modify the appropriate active/reactive injection equations. For branch $e=(i,j)$, let $t_e$ be the complex off-nominal tap, $y_e$ the series admittance, and $y_e^{f,sh},y_e^{t,sh}$ the terminal shunts. Its terminal currents obey
\begin{equation}
 \begin{bmatrix}I_{e,f}\\ I_{e,t}\end{bmatrix}=
 \begin{bmatrix}
 (y_e+y_e^{f,sh})/|t_e|^2&-y_e/t_e^*\\
 -y_e/t_e&y_e+y_e^{t,sh}
 \end{bmatrix}
 \begin{bmatrix}V_i\\V_j\end{bmatrix}. \label{eq:terminal-current}
\end{equation}
The PMU operator selects the actual instrumented terminal and orientation. Replacing terminal current with complete bus-injection current, or changing the tap and charging convention, changes the likelihood.

At the acquisition boundary, native measurements can include $V_{abc}$, $I_{abc}$, frequency, ROCOF, quality flags, and availability. Positive-sequence phasors define the balanced network likelihood used here. Negative- and zero-sequence components, when available, remain unbalance or integrity evidence rather than being mixed into the positive-sequence state. Ideal continuous-frequency channels satisfy
\begin{equation}
 f_i=f_0+\frac{1}{2\pi}\frac{d\angle V_i}{dt},\qquad
 \operatorname{ROCOF}_i=\frac{1}{2\pi}\frac{d^2\angle V_i}{dt^2}, \label{eq:frequency-rocof}
\end{equation}
but an implemented likelihood must use the causal estimator and filtering semantics of the corresponding PMU backend.

\subsection{Sparse PMUs and Requested State Function}

Both evidence campaigns use PMU buses
\begin{equation}
 \mathcal P=\{2,5,6,10,19,22,29,39\},\qquad |\mathcal P|=8. \label{eq:pmu-set}
\end{equation}
The unobserved set is $\mathcal U=\{1,\ldots,39\}\setminus\mathcal P$, with $|\mathcal U|=31$. The state-estimation campaign stacks rectangular voltage and controlled terminal-current components,
\begin{equation}
 \bm y_{\mathcal P,k}=\operatorname{col}_{p\in\mathcal P}
 [\Re V_{p,k},\Im V_{p,k},\Re I_{p\ell,k},\Im I_{p\ell,k}], \label{eq:pmu-vector}
\end{equation}
and requests the hidden complex-voltage function
\begin{equation}
 \bm z_{\mathcal U,k}=\operatorname{col}_{i\in\mathcal U}[\Re V_{i,k},\Im V_{i,k}]\in\mathbb R^{62}. \label{eq:hidden-target}
\end{equation}
The event campaign also uses voltage angle, frequency, availability, and, in its longer-window implementation, current and ROCOF. Measurement semantics are kept campaign-specific rather than declaring channels equivalent across simulators.

The topology contains 46 physical branches; the colored load buses identify the 16-source candidate set rather than a claim that every event family has been evaluated at those locations. The drawing is explanatory only: all physical responses and electrical-distance features use the audited branch data and admittance model.

The internal decision at time $k$ is
\begin{equation}
 \left(\widehat{\bm z}_{\mathcal U,k},\bm\Sigma_{z,k},
 \widehat c_k,\widehat K_k,\widehat{\mathcal S}^{\mathrm{phys}}_k,
 \widehat m_k,\widehat\ell^{\mathrm{meas}}_k,\mathcal C_k\right),
 \label{eq:joint-output}
\end{equation}
where $m_k$ denotes the integrity state and $\mathcal C_k\subseteq\mathcal H$ is a credible candidate set. A support is empty when no physical event applies. The candidate set is required because limited observability can make a forced Top-1 decision scientifically unjustified.

\subsection{Correctness and Evaluation Units}

State accuracy uses the mean hidden-voltage relative complex error (HVRE)
\begin{equation}
 \operatorname{HVRE}^{(r)}=\frac{1}{T_r|\mathcal U|}
 \sum_{k=1}^{T_r}\sum_{i\in\mathcal U}
 \frac{|\widehat V_{i,k}-V_{i,k}|}{\max(|V_{i,k}|,\epsilon)}. \label{eq:tve}
\end{equation}
This trajectory-and-bus aggregate is reported as a percentage. It is TVE-style but is not the standard per-frame synchrophasor TVE conformity statistic. Event detection, event-family macro-F1, exact physical Top-1/Top-3, and integrity-source Top-1 use their own declared populations. The joint correctness indicator is one only when every applicable component of \eqref{eq:joint-output} is correct; a correct event family cannot conceal a wrong source. Confidence intervals use an independently generated trajectory, event parent, or rebuilt plant as the statistical unit, never individual 30-Hz samples.

Causal inference permits only $\bm y_{0:k}$ at time $k$. A fixed-lag smoother, complete-window statistic, or centered temporal feature is retrospective and is labeled accordingly. Source generalization requires that physical source $\ell$ be absent from all source-labeled training and tuning, not merely that the test trajectory use a new random seed.
