\section{Introduction}
\label{sec:introduction}

\PARstart{A}{fter} a load is restored or a line is reclosed, physical state
continues to evolve. A second intervention may begin before that response
decays. With eight PMUs, the observed change can combine recovery from the
earlier event with forcing from a new source
(Fig.~\ref{fig:problem-method}(a)).

A detector may register this change without identifying its cause. We ask
whether a monitor can name the new load or line before it is restored,
and how many unmatched alarms it generates in doing so. Sequential
detectors test for changes in the law of the observations
\cite{willsky1976glr,nikiforov1995generalized,lai2000sequential,tartakovsky2014sequential}.
Existing grid methods compare outage hypotheses or match transient
trajectories to candidate faults
\cite{tate2008outage,chen2016quickest,rovatsos2017outage,warner2023highfidelity}.
Successive interventions create a further ambiguity because a restored
asset can still account for part of the next measured transient.

We use switched differential-algebraic equation (DAE) models to predict
each candidate response from the state inferred before its proposed onset.
A restored history stops contributing to the weight assigned to an
active intervention, but its predicted response can still explain incoming
reports until the bank compresses it. The same update therefore supports
three distinct outputs: an alarm, a source diagnosis and a restoration
message (Section~\ref{sec:narrative-method}).

We evaluate the bank against a continuous generalized likelihood ratio
(GLR) observer and an ExtraTrees classifier on held-out sequences with a
known catalog. The GLR tracks one continuous state, and ExtraTrees scores
sources from recent PMU features. Each procedure selects its threshold
on calibration data
under a target of one normal alarm per hour
(Section~\ref{sec:narrative-protocol}). A separate reset experiment changes
the estimated physical state within the bank and tests whether continuity
matters. To establish where the result applies, we examine errors under
network mismatch and independent per-PMU noise
(Section~\ref{sec:narrative-results}).
