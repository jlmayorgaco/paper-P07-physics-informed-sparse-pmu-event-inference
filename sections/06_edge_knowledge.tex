\section{Validated Benchmark and Experimental Protocol}
\label{sec:experimental-protocol}

\subsection{Benchmark Provenance and Numerical Gates}

The primary plant uses Julia 1.11.9, PowerDynamics.jl 5.0.0, and NetworkDynamics.jl 1.3.0 \cite{plietzsch2022powerdynamics}. It contains 39 buses, 46 branches, 19 loads, 10 sixth-order Sauer--Pai machines, nine AVR Type-I controllers, and nine TGOV1 governors. The descriptor realization has 192 coordinates: 114 differential and 78 algebraic. These parameters are package-defined tutorial data. We therefore classify the plant as a numerically validated pedagogical benchmark rather than an authoritative representation of an external grid.

The validation ladder checks the model before estimator error is scored. A same-plant static translation was audited after correcting tap orientation, shunts, line charging, and full-$Y_{\mathrm{bus}}$ injection accounting. The largest remaining static discrepancy is $1.71\times10^{-3}$~MVA in terminal flow. The controlled PMU operator agrees with the simulator to $2.71\times10^{-7}$~pu in complex voltage and $1.43\times10^{-14}$~pu in analytic/backend terminal current.

Dynamic validation checks the equilibrium, local modes, nonlinear trajectories, and linearization. The DAE equilibrium residual is $4.66\times10^{-13}$. After removing the reference mode, the least-damped physical pair is $-0.09818\pm\mathrm{j}0.42948$~s$^{-1}$. Nonlinear Rodas5P simulations remain finite for the audited perturbations. Amplitude sweeps satisfy
\begin{equation}
 \|\bm y_{\mathrm{NL}}(\epsilon)-\bm y_{\mathrm{LIN}}(\epsilon)\|_2\propto\epsilon^p, \label{eq:linearization-order}
\end{equation}
with fitted slopes between 1.982 and 2.000 for representative state, governor-reference, and load perturbations, consistent with first-order linearization error.

\subsection{Nominal Reconstruction and Calibration}

The nominal dataset contains 20 development and 100 test trajectories, each sampled at 30~Hz for 3~s. Perturbations are normal-operation changes to governor references, loads, or their combination. The equilibrium, linear model, $\bm P_0=10^{-2}\bm I$, $\bm Q=10^{-6}\bm I$, and $\bm R=10^{-6}\bm I$ are frozen before TEST. B0, B1, B2, and all B3 lags are evaluated on the same trajectories. A separate 30-trajectory calibration split fits U1/U2 temperatures and low-rank discrepancy variants; TEST is not used for selection.

Hidden truth is used only for post-hoc metrics. The eight observed buses are excluded from every primary reconstruction score. The phasor prediction is formed as $\bm V_0+\Delta\bm V$, and angle error is wrapped using $\operatorname{atan2}(\sin\Delta\vartheta,\cos\Delta\vartheta)$. These rules correct an earlier exploratory implementation that incorrectly interpreted $\angle\Delta V$ as the absolute angle; no superseded result from that implementation is retained.

\subsection{Physical Mismatch Campaign}

For each mismatch case, a fresh PowerDynamics plant is rebuilt from copied source tables, followed by power flow, dynamic initialization, and nonlinear simulation. The original package CSVs remain hash-identical. The seven families are network $R/X/B$ (M1), machine parameters (M2), governor parameters (M3), AVR parameters (M4), ZIP/load model (M5), operating-point redispatch (M6), and coupled mismatch (M7). Stress scale is $m\in\{0,0.25,0.5,0.75,1.0,1.25,1.5\}$. These are engineering stress-test ranges, not probability priors.

All 980 main-grid cases and all 175 refinement cases passed power-flow, initialization, and time-domain acceptance. B1, B2, U0, U2, and the adequacy score are frozen from nominal data. Bootstrap intervals use seeds as independent units. The plots read the frozen per-case table directly; a previously used refined breakpoint mixed aggregation definitions and is excluded.

\subsection{Oracle, Offset, and Physical-Map Adaptation Contracts}

The oracle subset compares the frozen estimator with true-equilibrium recentering and true local relinearization on the same mutated trajectories. Oracle quantities are evaluation-only. The offset-only recentering study uses new DEV seeds 101--110 and TEST seeds 201--220, disjoint from all earlier datasets. Its window, cadence, regularization, and activation threshold are selected on DEV and frozen before TEST. No event labels, hidden state, or mismatch family enter the R2-A estimate.

The corrected regularized physical-recentering campaign is a separate M6-only contract. It uses 30 fresh DEV cases from seeds 601--610 and 60 TEST cases from seeds 611--630, with 20 TEST equilibria at each of $m\in\{0.5,1.0,1.5\}$. DEV selects the nuisance scale, regularization, and continuation initialization from a small fixed grid. TEST uses only the observed voltage and terminal-current phasors; hidden voltages are revealed afterward for scoring. A solution is accepted only when the nonlinear optimizer succeeds, all outputs are finite, and the maximum AC residual is at most $5\times10^{-5}$. Rejections remain in the denominator; the frozen rejection table is empty. A six-case subset is also solved with an independent constrained optimizer, and its partial convergence status is reported rather than upgraded to full solver equivalence.

All numerical tables and empirical figures are regenerated from the hashed snapshot under \texttt{generated/frozen}. The build script checks the sample counts, acceptance flags, rank-deficient nuisance information, and preregistered adaptation-closure range before producing the tables and figures.

\subsection{Load-Source Inference Contract}

The load-source campaign uses the PowerDynamics plant and the same eight PMU buses, but it has its own frozen normal banks, event dictionary, and test manifests. The dictionary covers 16 candidate load buses listed in its manifest. Centered $\pm0.5\%$ nonlinear simulations define \,\eqref{eq:load-tangent}; the corresponding dictionary hash is fixed before the Bayesian tests. Candidate source and amplitude are inferred from the PMU window. The true source and true amplitude appear only in the evaluator.

V1 tests finite changes of $\pm1$, $\pm2.5$, $\pm5$, and $\pm7.5\%$ on 2,560 event and 320 no-event records. V2 expands normal calibration to 1,000 records, uses 500 normal and 640 event records for likelihood selection, then opens two TEST blocks. The weak block contains 9,600 events at magnitudes from 0.01 to 0.4\% and 800 no-event records. The finite block contains 8,000 events from $\pm1.25$ to $\pm9\%$. Noise seeds are disjoint across CAL, DEV, and TEST. A test record is one source--amplitude--noise realization; repeated samples within its 30-frame window are never counted as independent cases.

W2 and L2 are selected on CAL/DEV, respectively, and frozen for both V2 TEST blocks. The weak-event operating threshold is 0.5 posterior event probability. No TEST row enters covariance estimation, likelihood selection, prior selection, or threshold tuning. The campaign covers one physical family and a fixed topology; it does not validate simultaneous events, missing PMUs, or cross-simulator transfer.

\subsection{Event-Diagnosis Campaign and Signal Evidence}

The separate event campaign uses ANDES \cite{cui2021hybrid} and the same eight PMU buses. It contains 138 source configurations: one normal condition, 39 fault buses, 34 outage lines, ten generation connections, 18 load buses, eight missing-data PMUs, ten generation-and-missing pairs, eight bad-data PMUs, and ten prescribed mixed-event configurations. Five replicas per configuration give \LegacyEventTrajectories{} complete trajectories. Each physical trajectory lasts approximately 5~s, with the event scheduled at 2~s; missing or corrupted intervals last 0.7~s. Physical interventions are applied inside the simulator, whereas missing and corrupted values are applied to sampled measurements.

Three replicas per source configuration enter training, one development, and one test, producing 414/138/138 complete-trajectory splits. Consequently, the primary event benchmark evaluates new replicas at sources already represented in training. The separate asset-disjoint audit removes the physical source from all source-labeled fitting and tuning. Results from these contracts are reported side by side but never interpreted as the same generalization task.

The historical baseline is a hierarchy of extremely randomized trees. Its 136-feature version uses trailing voltage magnitude, angle, frequency, missingness, and a normalized disturbance score. The 448-feature version adds multiscale statistics, adaptive residuals, and simultaneous contrasts among PMUs. A deterministic availability gate handles directly observed dropout. These are physics-guided features and typed decision heads; they are not a DAE-constrained learning architecture, and the ensemble's leaf-vote scores are not treated as calibrated probabilities.

Figure~\ref{fig:event-signatures} uses the first labeled episode of six representative families in the 89.65-min RAW0001 reference simulation. The curves are measured simulator outputs, not sketches or smoothed reconstructions. They show why no single channel suffices: a fault creates a short voltage sag, an outage redistributes current, injection changes have slower frequency/current responses, and measurement failures require availability or phase-consistency information.
